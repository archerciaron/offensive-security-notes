# Offensive Security Notes

A personal knowledge base documenting my journey through offensive security,
built primarily around my study for the HackTheBox Certified Penetration
Testing Specialist (CPTS) certification.

## About this repository

This repo is where I consolidate what I learn as I develop my practical
penetration testing skills. Rather than just consuming material, I write
things up in my own words to deepen my understanding, build a reference I
can return to, and track my progress over time.

Each writeup focuses on a **technique or concept** — what it is, why it
works, how it's identified, and how it's remediated — reflecting the way I
think about security: not just how to exploit something, but how to explain
and fix it.

> Note: These notes cover concepts, methodology, and my own understanding
> of techniques. They do not contain solutions to specific HackTheBox
> machines or exam content, in line with HTB's terms.

## Why I'm doing this

I'm a cyber security professional with a background in vulnerability
management, moving deeper into hands-on offensive security. I believe the
best way to learn is to document as you go, so this repo serves three goals:

- **Reinforce learning** — writing a concept up in my own words is the
  fastest way to genuinely understand it.
- **Build a reference** — a searchable personal knowledge base I can draw on
  during engagements and future study.
- **Show my work** — a transparent record of how I think, how I approach
  problems, and how I'm progressing as a practitioner.
